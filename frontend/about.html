About me & my project

As I wrote, the project is a platform for learning DevOps practices. I work as a Linux and Windows Server Administrator on a daily basis and I am fascinated by working in a DevOps position. I have long been intrigued by topics such as Docker, Kubernetes, the Golang language and Cloud Technologies such as Azure or AWS. The project is an introduction to something bigger for me. And something bigger on my GitHub? Well, soon :)

The project itself contains two components. Frontend and Backend. The frontend will be simple and will contain things like Tailwind Framework for decoration and fetch in JavaScript, and the rest as standard in HTML. Later I plan to create Backend in Go Language (Golang) and do containerization, then move on to creating containers and possibly deploying the application to Kind (Kubernetes in Docker). Alternatively, the service can be made without containerization and orchestration on the server itself, where something like Nginx will appear for serving static files and Nginx as Reverse Proxy.
